## 수정 및 개선 내역
1. 경기 결과 및 경기 포기 재호출에 대한 중복 저장·보상·경기 인덱스 변경 방지
2. 역할 구분 없이 동일한 9회말 끝내기 판정 및 9회초 홈팀 리드 상황의 9회말 생략
3. 손상된 저장 데이터 검증 및 레거시 리그 기록 보완
4. 브라우저 저장소 쓰기 실패 시 게임 크래시 방지
5. 선수 이름을 HTML 문자열 대신 입력 요소의 `value` 속성으로 전달하여 HTML 삽입 방지
6. 모바일 선수 생성 창의 반응형 폭·스크롤 처리
7. 스코어보드 이닝·팀명·B/S/O·루상 정보 겹침 수정, 탑다운 경기 화면에서 점수판 유지
8. 마을 경기장·쇼핑몰·훈련소 클릭 위치를 배경 이미지의 실제 건물에 맞게 조정
9. GitHub Actions에 Chromium 스모크, 화면 증거, 전체/프로덕션 의존성 감사 추가

## 남아 있는 위험 및 검증 범위의 한계
- [보안 후속 #3](https://github.com/nalkarowndal/yakkyu/issues/3): Vite 5 및 전이 의존성 5개 항목의 업데이트 필요. 개발·프리뷰 서버를 공용 네트워크에 노출하지 말 것.
- [추가 실플레이 #4](https://github.com/nalkarowndal/yakkyu/issues/4): 9~12회 완주, 144경기 시즌, 도루·병살·송구·수비 실책, 실제 모바일 기기, 장시간 메모리 및 FPS 검증 필요.
- 브라우저 스모크는 주요 동선과 런타임 오류를 확인하며, 모든 투구·타격 물리 및 장시간 경기의 정밀 밸런스까지 보증하지 않음.
- 병원 핫스팟과 배경 아트의 의미상 위치, 모바일 플레이 UI의 세부 가독성 개선은 추후 UI 단계로 이관.
- 보안 점검의 0건은 `--omit=dev`로 설치 범위를 제한한 결과이며, 전체 프로젝트에 보안 취약점이 없다는 의미는 아님.
